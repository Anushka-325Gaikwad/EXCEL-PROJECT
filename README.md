# 📊 Student Result Analysis – Excel Dashboard

## 📌 Overview

**Student Result Analysis** is an interactive **Microsoft Excel Dashboard** created to analyze and visualize student academic performance.

The project uses **Excel formulas, PivotTables, PivotCharts, Slicers, and Conditional Formatting** to convert student marks into meaningful insights.

## 🔍 Key Dashboard Insights

* Provides a clear view of **overall student performance** through total marks and percentage.
* Enables **student-wise performance comparison** using interactive Slicers.
* Highlights **subject-wise strengths and weaknesses** through PivotCharts.
* Identifies **Pass/Fail distribution** for quick result analysis.
* Uses **Conditional Formatting and Data Bars** to highlight performance patterns.
* Allows quick identification of **highest and lowest-performing students and subjects**.
